### Zira Store JSON

## Zira Store es una tienda de aplicaciones de código abierto inspirada en F-Droid, a diferencia de otros. Zira tiene dos lugares officiales:
1. Github (apps dentro de Zira, JSON, etc).
2. Gitlab (desarollo de la app)

Lo que vamos a hablar hoy es el JSON, te preguntarás: ¿Qué es el JSON?

El JSON en Zira Store son múltiples JSONs, no uno. Para diferentes categorías, hay:
1. Categorías principales
2. Categporías secundarias, osea. Dentro de las principales

En el JSON, habrá algo así, ejemplo:
IA/
videojuegos/
tiendas/
gestor/
otros.

En la Wiki puedes encontrar documentación acerca de Zira. 

### En 2027

Zira Store está bajo amenaza, Google quiere cambiar la forma en la que instalas apps en tu dispositivo. Ahora, para 2027 puede que Zira NO funcione en dispositivos certificados por Google
